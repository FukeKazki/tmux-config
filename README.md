1. ghqの管理下にclone
   `ghq get git@github.com:FukeKazki/tmux-config.git`
2. シンボリックリンクを貼る
   `ln -s ~/Develop/github.com/FukeKazki/tmux-config/ ~/.config/tmux`
3. true color support
   `tic tmux-256color.terminfo.txt`
